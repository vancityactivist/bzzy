# Archived hardware

Designs that bzzy no longer builds. They're kept for the history and because parts of them carry over. Don't order from them.

| Folder | What it was | Why it's archived |
|---|---|---|
| [led-ring-revC/](led-ring-revC/README.md) | The LED ring board (rev C) that sat round the Waveshare ESP32-S3-Touch-LCD-1.69 | 2026-11-19: replaced by the merged [main board](../../docs/hardware/main-board.md). Never ordered. Its generator still writes `case/board_dims.scad` |

Earlier ring revisions (B and B2) only exist as fab files in the project's shared files (`hardware/archive/led-ring/`); rev C replaced them in place in this repo, so they're in the git history too.
